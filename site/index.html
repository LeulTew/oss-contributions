      Data & help

      Read-only, selected public PRs. Review requests, CI and conversation are independent. Comments are not automatically author tasks. An unclassified account is not assumed human.

      The shared snapshot is scheduled every 15 minutes. GitHub can delay or drop runs; public schedules disable after 60 days without repository activity. This is polling, not push. The browser checks the published JSON every five minutes while visible.

      Refresh discussion reads only the selected public PR and its activity from api.github.com, without a token. It does not refresh CI. Limits: five-minute cache, 35 requests per hour, 10 per attempt, 20-second timeout, cancellation and rate-limit backoff. Anonymous quota is shared by IP; storage failures can limit coordination to this tab.

      Observation times differ from GitHub's PR-updated time. First-recorded heads are metadata, not changes; subsequent head events are observations, not claimed push times. Merged and closed records retain historical dates. Failures retain labeled last-good evidence; missing data is never green.

      No credentials, analytics, upstream writes or account-wide history. Comments use safe Markdown with original text and source links retained. Images are not loaded. Review quotations retain their exact wording.
