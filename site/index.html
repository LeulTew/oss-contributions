      About this tracker

      What the statuses mean

      PR state, review decisions and CI are independent. A comment is not automatically an author task. Earlier-head decisions and stale observations stay labeled. An unclassified account is not assumed human.

      Initial heads are baseline metadata, not activity. Subsequent head events are observations, not claimed push times. Merged and closed records retain historical evidence. CI success is not proof that every intended test executed.

      Refresh & API limits

      The shared snapshot is scheduled every 15 minutes. GitHub may delay or drop runs; public schedules disable after 60 days without repository activity. The browser checks published JSON every five minutes while visible. This is polling, not push.

      Refresh discussion reads only the selected public PR and its activity from api.github.com without a token. It does not refresh CI. Limits: five-minute cache, 35 requests per hour, 10 per attempt, 20-second timeout, cancellation and rate-limit backoff. Anonymous quota is shared by IP; storage failures can limit coordination to this tab.

      Sources, privacy & formatting

      Only selected public PRs are included. No credentials, analytics, upstream writes, private work or account-wide history. Failed requests retain labeled last-good evidence.

      Messages use safe Markdown; original text, body hashes and source links remain intact. Images are not loaded. Formatting failures leave the original text available. Review quotations retain their exact wording and apply only to their original contribution.

      Review replies are not nested unless their source relationship is available; the current snapshot records a flat timeline.
