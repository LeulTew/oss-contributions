      Review, CI, conversation

      Review requests come from explicit review states. Comments are context, not automatically tasks for the author. Check failures and workflows waiting for maintainer approval have separate views. A GitHub account is labeled human only when verified; unclassified accounts remain unclassified.

      Polled, never presented as push

      The shared snapshot is scheduled every 15 minutes, but GitHub can delay or drop runs. Public schedules disable after 60 days without repository activity. Actual observation times and stale warnings stay visible. No keepalive commits or guaranteed instant delivery.

      Refresh, quota and historical records

      Reload snapshot reads the published JSON, checked every five minutes while this tab is visible. Check this PR now makes a bounded, tokenless request to api.github.com for only the selected PR and its public discussion. GitHub's anonymous quota is shared by IP; refresh may be unavailable. Short-lived cached results and rate-limit backoff prevent repeated requests. Direct refresh does not make scheduled CI evidence newer.

      Merged and closed records keep historical observation dates instead of routine polling. Branch-update times mean the change was observed, not that a push occurred at that time. Older cached snapshots remain readable with activity explicitly unavailable until refreshed. On failure, last-good evidence remains labeled; a missing observation is never green.
